# Threads

A campaign timeline notebook for tabletop groups. Each party, character or strand of world events gets its own colored thread, running side by side day by day, so you can see what everyone was doing at the same time, who was with whom, and where the threads crossed.

It's a single web page: no accounts, no installs and no server code. Each player's notes are saved in their own browser, and one person, usually the DM, keeps the shared version.

**Try it:** [the example campaign, "The Salt Road"](ADD-YOUR-SITE-ADDRESS-HERE)

## What it does

- Parties, characters and world events side by side, with connections between them and shaded spans for journeys, sieges and other realms.
- Who's where on every day, including joins, departures, deaths and mid-day moves between parties.
- Places where time runs faster or slower than the rest of the world, each event marked with its local day.
- Follow any name across the whole campaign.
- Players keep their own notes and send additions to the DM, who reviews and merges them.

## Using it

Read the [quick start guide](GUIDE.md). It covers reading the timeline, keeping your own notes, sending additions to the keeper, and troubleshooting.

## Hosting your own

1. Download `index.html` from this repository.
2. Put it on any web host. GitHub Pages, Netlify and Cloudflare Pages all work, or any server that serves static files.
3. To start your own campaign, open the page, choose **New timeline**, and build it in your browser.

To publish your campaign so your group sees it, export it and place the export inside `index.html` in place of the built-in example. The guide's "For the keeper" section covers the routine.
